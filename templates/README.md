# 可编辑模板：先填证据，再做排版

版本 1.0.0｜2026-11-13｜作者：AI 酋长 Andy

所有模板完整开放。Markdown 可用任意文本编辑器修改；CSV 可在 Excel、Numbers、Google Sheets 等工具中导入，编码为 UTF-8。CSV 第一行是字段名，第二行是明确标注的教学示例，第三行是待填写行。复制后保留字段，删除教学行并填写自己的真实内容。

**不要把教学示例、虚构雇主、模拟研究记录或教材作者联系方式当成自己的申请材料。** 官方截止、资格和许可信息需按具体岗位逐项核验。对于未知字段，写“待核实”和下一步，不凭印象补满。

## CSV 填写说明与验收

### 1. 岗位拆解表

**输入：** 官方 JD 正文、页面 URL、访问日期、个人毕业与身份信息。  
**操作：** 保留职位原名；把“必须”“优先”“职责”分开；复制窗口原文，另记时区；不要把岗位层级从标题猜出来。  
**产出：** 每个目标岗位一行，关键要求可另增行。  
**验收：** 任一要求能回到官方原文；未知条件有待核实动作；毕业时间不套其他国家经验。  
**失败处理：** 页面失效时保留历史样本标签，寻找当前岗位；没有正文不能标成已核验。

`要求性质`建议使用：硬门槛、优先条件、工作职责、待核实。`申请窗口原文`不能用自己的内部截止替代。

### 2. 能力证据表

**输入：** 已拆解 JD 和本人项目。  
**操作：** 一条要求对应一个最强证据，填写个人动作与证据强度，再写不能证明的部分。  
**产出：** 一张能够指导补材料的缺口表。  
**验收：** 链接可以打开；读者能分清经历、能力、表达和资格缺口。  
**失败处理：** 找不到证据就写缺口，不用课程名或工具名代替真实动作。

`来源强度`可写：真实记录、经许可的团队产物、个人复盘、模拟材料、未来计划。它们不是同一强度。

### 3. 研究观察表

**输入：** 经同意的匿名笔记、观察记录或明确标注的模拟素材。  
**操作：** 原话与解释分列；记录反例；每条保留来源与公开范围。  
**产出：** 可回溯的材料台账。  
**验收：** 不把模拟编号变成参与者编号；不混淆作者判断与参与者表达。  
**失败处理：** 没有公开许可时只保留去敏摘要或不公开；没有采集记录时不写访谈结论。

### 4. 决策日志

**输入：** 一个尚待决定的问题与当时可用证据。  
**操作：** 写至少两个选项、最终选择、代价和推翻条件。  
**产出：** 可解释“为什么”的记录。  
**验收：** 推翻条件是可观察证据；没有为了美化结论删掉反例。  
**失败处理：** 无法说明代价时重做比较；未知影响保持未知，不补精确评分。

### 5. 指标口径表

**输入：** 要做的产品决策、任务定义和可取得的数据。  
**操作：** 先定统计单位、分子分母、时间范围与排除规则，再填写数据。  
**产出：** 他人可复算的指标字典。  
**验收：** 重复尝试不冒充独立用户；放弃与失败不静默删去；无数据写未采集。  
**失败处理：** 数据不足时报告具体观察和限制；不能用点击量替代任务成功。

### 6. 面试复盘表

**输入：** 一次练习的录音或逐条笔记。  
**操作：** 写核心判断、证据、最难追问；下一轮只选一个改进。  
**产出：** 能复练的记录。  
**验收：** 改进项可观察，例如“先澄清分母”，不是“更自信”。  
**失败处理：** 若没做过项目，补真实行动；若只是表达乱，重练同题，不急着换新题。

评分为本册自练量表，不是任何雇主的录用线：0=没有材料；1=明显缺失；2=基本可理解；3=有依据且能被追问；4=能处理反例与变化。没有导师评分也可以用，但要保留评分人和依据。

### 7. 申请倒排表

**输入：** 官方窗口原文、具体时区、个人毕业和可入职时间。  
**操作：** 先核对资格与日期，再倒排研究、材料、练习和提交；内部截止单独填写。  
**产出：** 每项有依赖、负责人和证据的动作表。  
**验收：** 不把虚构日期当招聘窗口；不把学生兼职规则当毕业后的工作权。  
**失败处理：** 窗口不明时查官方或联系招聘方；不明示时区时不猜测，尽早处理并记录不确定性。

## 如何使用整套模板

先填岗位拆解，再填能力证据；选择最关键缺口，开展真实研究或项目；用决策日志记录取舍，用原型和指标说明如何验证；最后整理作品集、简历和面试复盘。模板服务于行动，不要求把所有表都填满才允许申请。
